# Benchmark Roadmap

After the v2.0.0 protocol is frozen, benchmark extensions are ordered as follows:

1. **Ablation**
   Isolate the contribution of table content, visible labels, interface format,
   context size, and source-grounded state with matched-budget controls.

2. **Attribution**
   Evaluate whether a response is supported by the correct source rows, columns,
   and cells, with explicit provenance and programmatic evidence scoring.

3. **Reasoning**
   Extend controlled table operations toward composed reasoning while preserving
   source-grounded, programmatically computed answers.

4. **Multi-view evaluation**
   Add equivalent Markdown, JSON, and key-value table renderings, including
   held-out-view transfer, without changing the underlying source fact or gold.

These items are planned work and are not claims of v2.0.0.
